# Day 001 - Network Devices & Basic Connectivity

## Objective

* Learn about common network devices and their roles in a network.
* Understand how routers, switches, end devices, servers, and firewalls are used.
* Build a basic network topology and establish connections between the devices.

## Topology / Setup

Created a basic network topology in Cisco Packet Tracer consisting of:

* Router
* Switch
* Client/PC
* Server
* Firewall

Connected the devices to understand how different components communicate within a network.

## What I Learned

* **Router:** Connects different networks and forwards packets based on IP addresses.
* **Switch:** Connects devices within a local network and forwards frames using MAC addresses.
* **Client/PC:** An end device that sends and receives data over the network.
* **Server:** Provides services and resources to other devices on the network.
* **Firewall:** Helps control and filter network traffic based on defined security rules.
* Learned how different network devices work together to form a basic network.
* Gained initial hands-on experience creating a network topology in Cisco Packet Tracer.
