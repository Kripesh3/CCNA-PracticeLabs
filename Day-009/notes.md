# Day 009 - Switch Interfaces & Auto-Negotiation

## Objective

* Learn about switch interfaces and their basic configuration.
* Practice using commands to view and configure switch interfaces.
* Understand speed, duplex, and auto-negotiation on switch interfaces.
* Learn how to configure multiple interfaces at once.

## Configuration Summary

* Used `show interfaces status` to view the status and information of switch interfaces.
* Configured **speed** and **duplex** settings on switch interfaces.
* Learned about **auto-negotiation** and how connected devices negotiate speed and duplex settings.
* Practiced selecting a **range of interfaces** to apply configurations to multiple ports at once.

## What I Learned

* Switch interfaces are the physical ports used to connect network devices.
* The `show interfaces status` command provides a quick overview of interface status, VLAN, duplex, speed, and type.
* **Speed** determines the data transmission rate of an interface.
* **Duplex** determines whether an interface can transmit and receive data simultaneously.
* **Auto-negotiation** allows connected devices to automatically negotiate compatible speed and duplex settings.
* Interface range configuration allows the same configuration to be applied to multiple interfaces efficiently.
* Gained hands-on experience configuring and inspecting switch interfaces using Cisco IOS CLI.
