# Day 011 - Static Routing & Connected Networks

## Objective

* Understand how routers identify directly connected and local networks.
* Learn the fundamentals of static routing.
* Practice configuring static routes between different networks.
* Learn and practice Cisco IOS commands used for basic router configuration and routing.

## Topology / Setup

Created a multi-router topology in Cisco Packet Tracer and configured the routers to enable communication between different networks.

Practiced configuring interfaces and static routes, then tested connectivity between the networks.

## Configuration Summary

* Performed basic pre-configuration on routers.
* Configured router interfaces with IPv4 addresses.
* Identified **connected** and **local** routes.
* Configured **static routes** to reach remote networks.
* Used Cisco IOS commands to view and verify routing information.

## What I Learned

* A **local route** identifies the IP address assigned to a router interface.
* A **connected route** represents a network that is directly connected to a router interface.
* A **static route** is manually configured by a network administrator to tell a router how to reach a remote network.
* Routers use their routing table to determine where packets should be forwarded.
