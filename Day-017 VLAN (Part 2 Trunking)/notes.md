# Day 017 - Trunking & Inter-VLAN Routing

## Objective

* Understand the concept of VLAN trunking.
* Learn why trunking is needed in a network.
* Understand how trunking works between network devices.
* Learn the basic Cisco IOS commands used to configure trunk ports.
* Configure trunking and enable communication between different VLANs.

## Topology / Setup

Created a Cisco Packet Tracer topology with multiple VLANs and configured a trunk link between network devices to carry traffic from multiple VLANs.

## Configuration Summary

* Configured VLANs on the switch.
* Configured a switch interface as a trunk port.
* Used Cisco IOS commands to configure and verify trunking.
* Configured inter-VLAN routing.
* Tested communication between devices in different VLANs.

## What I Learned

* A trunk link carries traffic from multiple VLANs over a single physical link.
* Trunking is necessary when VLAN information needs to travel between switches or between a switch and a router.
* VLAN tagging is used to identify which VLAN a frame belongs to when it travels across a trunk.
* Trunking reduces the need for separate physical links for each VLAN.
* Learned the basic Cisco IOS commands for configuring and verifying trunk ports.
* Gained hands-on experience configuring trunking and implementing inter-VLAN routing in Cisco Packet Tracer.
