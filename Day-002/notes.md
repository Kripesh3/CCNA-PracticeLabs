# Day 002 - Network Cables & Device Connectivity

## Objective

* Learn about different types of network cables.
* Understand which cable is appropriate for connecting different network devices.
* Practice connecting network devices using the correct cables in Cisco Packet Tracer.

## Topology / Setup

Created a basic network topology in Cisco Packet Tracer and connected different network devices using appropriate cables.

Practiced using:

* Copper Straight-Through
* Copper Cross-Over
* Multimode Fiber-Optic
* Single-Mode Fiber-Optic

## What I Learned

* **Copper Straight-Through:** Used for connecting different types of devices, such as a PC to a switch or a switch to a router.
* **Copper Cross-Over:** Used for connecting similar types of devices, such as switch-to-switch connections.
* **Multimode Fiber-Optic:** Uses multiple light paths and is commonly used for shorter-distance fiber connections.
* **Single-Mode Fiber-Optic:** Uses a single light path and is designed for longer-distance fiber connections.
* Learned that selecting the appropriate cable depends on the devices, interfaces, and type of connection being established.
* Gained hands-on experience connecting different devices and working with various cable types in Cisco Packet Tracer.
