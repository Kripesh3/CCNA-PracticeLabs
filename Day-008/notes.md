# Day 008 - IPv4 Addressing & Router Configuration

## Objective

* Learn the fundamentals of IPv4 addressing.
* Understand network ID, broadcast address, first usable address, and usable host addresses.
* Practice configuring IPv4 addresses on a router using Cisco IOS commands.

## Topology / Setup

Created a basic network topology in Cisco Packet Tracer and configured IPv4 addresses on router interfaces.

## Configuration Summary

* Configured IPv4 addresses on router interfaces.
* Used Cisco IOS commands to configure and verify router interfaces.
* Practiced identifying network and host portions of IPv4 addresses.

## What I Learned

* IPv4 addresses consist of a **network portion** and a **host portion**.
* Learned about different IPv4 address classes and their default subnet masks.
* Learned how to identify:

  * Network ID
  * Broadcast address
  * First usable host address
  * Total usable addresses
* Practiced calculating the number of hosts available in a network.
* Learned basic Cisco IOS commands used for router configuration and verification.
* Gained hands-on experience configuring IPv4 addresses on a router in Cisco Packet Tracer.
