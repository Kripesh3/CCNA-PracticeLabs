# Day 004 - Basic Device Security

## Objective

* Learn the basics of securing Cisco network devices.
* Configure passwords on a switch to restrict unauthorized access.
* Encrypt configured passwords and save the configuration for persistence.

## Topology / Setup

Used Cisco Packet Tracer to configure basic security settings on a Cisco switch.

## Configuration Summary

* Configured passwords on the switch for basic device access.
* Enabled password encryption to prevent passwords from being stored in plain text.
* Saved the running configuration to the startup configuration.

## What I Learned

* Basic device security is important for preventing unauthorized access to network devices.
* Cisco IOS provides different mechanisms for securing access to network devices.
* Password encryption helps protect configured passwords from being displayed in plain text.
* The **running configuration** exists in memory, while the **startup configuration** is stored and loaded when the device boots.
* Saving the running configuration to the startup configuration ensures that changes are preserved after a device restart.
