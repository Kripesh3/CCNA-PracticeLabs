# Day 018 - Multilayer Switching & Inter-VLAN Routing

## Objective

* Understand the concept of multilayer switching.
* Learn why multilayer switches were introduced and their importance in modern networks.
* Understand how multilayer switches perform Layer 3 routing.
* Learn how to integrate a multilayer switch into a network topology.
* Configure inter-VLAN routing using a multilayer switch.

## Topology / Setup

Created a Cisco Packet Tracer topology using a multilayer switch and multiple VLANs. Configured the multilayer switch to perform routing between VLANs.

## Configuration Summary

* Created and configured multiple VLANs.
* Configured the multilayer switch for Layer 3 functionality.
* Configured Switch Virtual Interfaces (SVIs) for the VLANs.
* Enabled inter-VLAN routing on the multilayer switch.
* Configured end devices with the appropriate IP addresses and default gateways.
* Tested communication between devices in different VLANs.

## What I Learned

* A multilayer switch combines the functionality of a Layer 2 switch and a Layer 3 router.
* Multilayer switches were introduced to provide faster and more efficient routing within LAN environments.
* They can perform inter-VLAN routing without requiring a separate router.
* SVIs provide Layer 3 interfaces for VLANs and act as default gateways for devices in those VLANs.
* Multilayer switching can reduce the limitations associated with traditional Router-on-a-Stick designs.
* Gained hands-on experience integrating a multilayer switch into a network and successfully implementing inter-VLAN routing.
