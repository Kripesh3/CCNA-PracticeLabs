# Day 003 - OSI Model & Packet Flow

## Objective

* Learn about the 7 layers of the OSI model.
* Understand the role of each layer in network communication.
* Observe how data moves through different OSI layers using Cisco Packet Tracer's Simulation Mode.

## Topology / Setup

Used Cisco Packet Tracer to create a basic network and observed packet communication in **Simulation Mode**.

Examined how data is processed through the different layers of the OSI model as it travels between network devices.

## What I Learned

* The OSI model consists of **7 layers**:

  1. Physical
  2. Data Link
  3. Network
  4. Transport
  5. Session
  6. Presentation
  7. Application
* Each layer has a specific role in network communication.
* Observed the different layers involved when a packet travels through the network in Cisco Packet Tracer.
* Learned how the OSI model helps in understanding and troubleshooting network communication.
* Gained practical experience using **Simulation Mode** to visualize packet flow and the operations performed at different layers.
