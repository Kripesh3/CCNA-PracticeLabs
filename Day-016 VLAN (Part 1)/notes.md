# Day 016 - VLANs & Inter-VLAN Routing

## Objective

* Understand the concept and purpose of VLANs.
* Learn why VLANs are important in network design.
* Learn basic Cisco IOS commands used to create and configure VLANs.
* Configure VLANs and enable communication between different VLANs.

## Topology / Setup

Created a network topology in Cisco Packet Tracer with multiple VLANs and configured the router to enable communication between the VLANs.

## Configuration Summary

* Created and configured VLANs on the switch.
* Assigned switch interfaces to the appropriate VLANs.
* Configured the router for inter-VLAN communication.
* Configured static routing between VLAN networks.
* Tested communication between devices belonging to different VLANs.

## What I Learned

* A **VLAN (Virtual Local Area Network)** logically separates devices into different networks even when they are connected to the same physical switch.
* VLANs help divide a network into separate **broadcast domains**.
* VLANs can improve network organization, security, and traffic management.
* Learned basic Cisco IOS commands used to create VLANs and assign switch ports.
* Learned how **inter-VLAN routing** allows devices in different VLANs to communicate.
* Gained hands-on experience configuring VLANs and establishing communication between them using a router.
* Successfully practiced inter-VLAN communication using static routing in Cisco Packet Tracer.
